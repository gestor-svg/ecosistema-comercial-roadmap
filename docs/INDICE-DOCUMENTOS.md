# Índice de documentos del Ecosistema Comercial

Este archivo es el control central de todos los documentos (manuales, whitepapers, kits) que la hoja de ruta necesita. Nada se redacta por adelantado: cada documento se crea **justo cuando su tarea del checklist llega**, pidiéndoselo directamente a Claude.

## Cómo pedir un documento

1. Abre una conversación con Claude (puede ser esta misma sesión, o una nueva pegando el link de este repositorio).
2. Copia el **prompt sugerido** de la tabla de abajo tal cual, o ajústalo.
3. Dile dónde debe entregarlo:
   - Si es un **documento interno** → pídele que lo guarde como archivo Markdown en `/docs/<nombre-del-archivo>.md` de este repositorio.
   - Si es un **documento externo** (para aliados/clientes) → pídele que lo entregue como Word, PDF o Google Doc, y súbelo tú mismo a la carpeta de Drive indicada (o pídele a Claude que lo suba directamente si tiene conectado Google Drive).
4. Cuando esté listo, actualiza la columna **Estado** de este archivo a `✅ Listo` y agrega el link real.
5. Opcional: marca la tarea correspondiente como completada en la PWA — el checklist y este índice son dos vistas del mismo trabajo.
